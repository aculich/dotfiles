# Archive Directory

This directory contains archived versions of old configuration files.

## Structure

- `old-configs-YYYYMMDD_HHMMSS/` - Backups of configuration files from specific dates

## Purpose

These are backups of your previous configurations, kept for:
- Reference if you need to see how something was configured before
- Rollback if needed (use the rollback script in the backup directory)
- Historical record of configuration changes

## Cleanup

You can safely delete old archives after verifying the new setup works, but it's recommended to keep at least the most recent backup.
