# Umbrella `incoming/` (template)

Copy to repo root as `incoming/README.md` when bootstrapping a multi-engagement client repo.

Unclassified drops land here first. Tracked workflow files: `README.md`, `ROUTING-LOG.md`, `opportunities/README.md`, `_review/README.md`. Raw `.eml` / PDFs are typically gitignored; see root `.gitignore` negation patterns.

After routing each item, append **`ROUTING-LOG.md`** and move originals to `incoming/processed/YYYY-MM/`.

For classification heuristics and opportunity stubs, see **`process-umbrella-incoming`** skill.
