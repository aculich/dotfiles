# Converge and articulate

End the envisioning arc with **commitments** and **interfaces** to the next phase.

## When to Use

- Divergence produced clusters that need picking.
- Executives want a one-page decision, not more whiteboards.
- You are about to invoke a planning skill and need a stable brief.

## Workflow

1. **Decision record** — decision, date, owner, alternatives considered (link to clusters from [divergent-explore](../divergent-explore/SKILL.md)).
2. **Prioritized bets** — rank 1–3 with rationale and kill criteria.
3. **Open questions** — each tagged `must answer before build` vs `can learn live`.
4. **Handoff brief** — single markdown section: goal, non-goals, audience, success signals, risks, suggested next milestones. This block should paste cleanly into a plan doc.
5. **External routing** — point the user to the right downstream skill family using [SKILL-LANDSCAPE-PLANNING-CANDIDATES.md](../../../../docs/research/SKILL-LANDSCAPE-PLANNING-CANDIDATES.md) (superpowers brainstorm/write plans, compound ce-plan / ce-brainstorm, gstack plan reviews, and so on).
6. **Stop rule** — if new contradictions appear, reopen [unpack-the-question](../unpack-the-question/SKILL.md) instead of stacking plans on mushy goals.

## Principles

- **Write decisions**; spoken alignment does not survive Slack velocity.
- Explicitly list **deferred** options—silence reads as rejection without reasons.
- Keep the handoff brief under one screen where possible; link out for depth.
