## Conventions

- **Status values:** `awaiting-response`, `awaiting-action-by-us`, `actioned`, `filed-only`, `needs-review`, `closed`.
- **Awaiting:** name (or `us`) and the specific thing.
- Keep this file under one screen — promote older closed threads out of the table once they're no longer near-term.
