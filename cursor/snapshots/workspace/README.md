# Workspace snapshots

Files named `cursor-workspace-YYYY-MM-DD_HH-MM-SS.{json,txt,-extensions.txt}` from [dump-cursor-windows.sh](../../dump-cursor-windows.sh). Override output location with `SNAPSHOT_DIR`.

New dumps are gitignored by default (see repo `.gitignore`); use `git add -f` to commit a snapshot intentionally.
