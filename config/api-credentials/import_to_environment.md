# Importing API Credentials into 1Password Environment

This guide explains how to import the exported `.env` file into the `default-1234` 1Password Environment.

## Prerequisites

1. 1Password desktop app installed and running
2. `default-1234` environment already created in 1Password
3. `.env` file generated by `populate_environment.sh`

## Step-by-Step Instructions

### 1. Generate the .env File

Run the populate script:

```bash
~/dotfiles/config/api-credentials/populate_environment.sh
```

This will create `/tmp/default-1234.env` with all 81 API credentials.

Or specify a custom output file:

```bash
~/dotfiles/config/api-credentials/populate_environment.sh /path/to/custom.env
```

### 2. Open 1Password Desktop App

1. Launch the 1Password desktop application
2. Sign in to your account

### 3. Navigate to Environments

1. Click on **Developer** in the sidebar (or use the menu: **View > Developer**)
2. Click on **Environments**
3. Select the **default-1234** environment

### 4. Import the .env File

1. In the environment view, look for an **Import** or **Import .env file** button
2. Click it and select the generated `.env` file (default: `/tmp/default-1234.env`)
3. Review the imported variables
4. Confirm the import

### 5. Configure Local .env File Destination

After importing, configure where the environment should mount a local `.env` file:

1. In the environment settings, find **Local .env file** or **Destination** settings
2. Set the path where you want the `.env` file to be created (e.g., `~/dotfiles/.env`)
3. Save the configuration

### 6. Verify the Import

1. Check that all 81 credentials are listed in the environment
2. Verify that the local `.env` file is created at your configured destination
3. Test that the environment variables are accessible

## Troubleshooting

### Environment Not Found

If `default-1234` doesn't exist:
1. In 1Password, go to **Developer > Environments**
2. Click **+** or **New Environment**
3. Name it `default-1234`
4. Follow the import steps above

### Import Fails

- Ensure the `.env` file format is correct (KEY=value, one per line)
- Check that you have write permissions to the file
- Verify the 1Password desktop app is up to date

### Variables Not Appearing

- Refresh the environment view
- Check the `.env` file for syntax errors
- Ensure all credentials have valid values (not null or empty)

## Notes

- The `.env` file contains sensitive credentials - handle with care
- Consider deleting the temporary `.env` file after successful import
- Dollar-sign variable references (like `$CLAUDE_API_KEY`) are preserved as-is
- The environment will sync the `.env` file automatically when credentials are updated in 1Password
